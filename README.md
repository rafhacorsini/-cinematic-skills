# 🎬 Cinematic Skills

Skills para transformar sites genéricos feitos por IA em **experiências cinematográficas**.

## Instalação (Claude Code)

```bash
/plugin marketplace add rafhacorsini/cinematic-skills
/plugin install direction@cinematic-skills
```

## Skills

### `/direction`
Direção de arte **inicial e interativa**. Roda *antes* de construir o site: conduz
você por vibe, pareamento de fontes, arquitetura de seções, mood de paleta e
intensidade de movimento — e gera um `DIRECTION.md` que orienta toda a construção.

> Tira a página da "cara de template" antes da primeira linha de código.

## Fluxo recomendado

```
npx motion-ai          # 1. instala o movimento (Motion AI Kit)
/direction             # 2. define o rumo cinematográfico
                       # 3. parte pra execução
```
